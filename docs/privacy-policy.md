# Política de Privacidade

## Scan NFC-e

O Scan NFC-e permite que o usuário leia notas fiscais eletrônicas de consumidor, visualize compras e acompanhe gastos.

## Dados tratados

O aplicativo pode tratar:

- nome e e-mail informados no cadastro
- senha protegida pelo backend
- notas fiscais lidas pelo usuário
- informações de itens, valores, datas e estabelecimento das compras

## Finalidade de uso

Os dados são usados para:

- autenticar o acesso do usuário
- permitir recuperação de senha
- salvar notas fiscais vinculadas à conta
- exibir análises de gastos e comparação de preços

## Permissões do dispositivo

- câmera: usada para leitura do QR Code da NFC-e
- internet: usada para comunicação com a API e com a central de ajuda
- vibração: usada como feedback durante a leitura

## Compartilhamento

Os dados não são compartilhados com terceiros para fins de publicidade. Eles são utilizados apenas para viabilizar os fluxos do próprio ecossistema Scan NFC-e.

## Armazenamento

Parte das informações de sessão pode ser mantida localmente no dispositivo por armazenamento seguro, e os dados da conta e das notas ficam persistidos no backend da aplicação.

## Direitos do usuário

O usuário pode:

- acessar sua conta
- atualizar seu nome
- excluir notas salvas
- solicitar recuperação de senha
